# Compare PDF Forms and Generate JSON & Visual Diff Using Aspose.Pdf
This tutorial demonstrates how to compare two PDF documents that contain form fields with Aspose.Pdf for .NET. It automatically evaluates the values of each field, produces a detailed JSON report of any differences, and creates a side‑by‑side visual diff PDF so you can see changes at a glance.

## Frequently asked questions

**Q: What happens if the two PDFs have a different number of pages?**  
A: The `TextPdfComparer.CompareDocumentsPageByPage` method compares pages that exist in both documents; any extra pages in the longer PDF are reported as added or removed in the JSON diff and appear as whole‑page differences in the side‑by‑side PDF.

**Q: Do I need to enable a special option to compare form field values?**  
A: No extra flag is required—`ComparisonOptions` automatically evaluates form field values, so field changes are included in the `pageDiffs` returned by `TextPdfComparer.CompareDocumentsPageByPage`.

**Q: My JSON report is empty even though the PDFs look different; why?**  
A: Make sure the files are successfully loaded (the `File.Exists` check) and that you are using the same `ComparisonOptions` instance; if the PDFs contain only images or non‑text elements, `TextPdfComparer` will not detect visual differences, only textual/form‑field changes.

**Q: Will the side‑by‑side diff PDF preserve the original form fields?**  
A: The visual diff generated by `SideBySidePdfComparer.Compare` is a new document that shows differences side‑by‑side and does not retain interactive form fields from the source PDFs.
