# How to create PDF documents with Aspose.PDF for Java

Aspose.PDF for Java is a robust library that enables developers to generate, edit, and convert PDF files programmatically. In this overview you’ll discover how to **how to create PDF** files from scratch, from templates, and from other source formats while customizing layout and appearance.

## How to create PDF documents with Aspose.PDF for Java

Load the Aspose.PDF JAR into your project, instantiate a `Document` object, add pages, insert text, images, or shapes, and finally call `save`. **`Document` is the core class that represents a PDF document and provides methods for manipulation.** This straightforward two‑step pattern—initialise + save—covers 95 % of typical PDF generation scenarios and works on any Java 8+ environment. For large or complex documents you can also stream pages to keep memory usage low.

### Why choose Aspose.PDF for Java?

Aspose.PDF for Java supports **50+ input and output formats** (including DOCX, HTML, SVG, and LaTeX) and can generate multi‑hundred‑page PDFs without loading the entire file into memory, thanks to its incremental write engine. The library processes a 300‑page report in under 4 seconds on a standard 2.5 GHz CPU, providing predictable performance for high‑throughput services.
