### Wyodrębnianie plików z portfolio PDF

#### Przegląd

Ta sekcja prowadzi Cię, jak **extract embedded files pdf** z portfolio PDF. Jest to szczególnie przydatne przy pracy z dokumentami zawierającymi wiele typów mediów lub plików danych.

#### Implementacja krok po kroku

**1. Załaduj źródłowe portfolio PDF**  

Załaduj swoje portfolio PDF do pamięci. Klasa `Document` jest obiektem najwyższego poziomu w Aspose.PDF, który reprezentuje pojedynczy plik PDF w pamięci.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. Pobierz kolekcję osadzonych plików**  

Metoda `getEmbeddedFiles()` zwraca kolekcję, która zawiera każdy plik osadzony w portfolio.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. Iteruj i wyodrębnij każdy plik**  

Iteruj po każdym elemencie w kolekcji i zapisz strumień pliku na dysk. Obiekt `FileSpecification` dostarcza oryginalną nazwę pliku oraz strumień zawartości.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

W tym fragmencie:
- `input` pobiera strumień zawartości każdego osadzonego pliku.
- Katalogi są tworzone w locie przy użyciu `mkdirs()`.
- Pliki są zapisywane na dysku przy użyciu buforowanego `FileOutputStream`.

#### Porady dotyczące rozwiązywania problemów

- **File not found:** Zweryfikuj, że ścieżka PDF (`Portfolio_output.pdf`) wskazuje prawidłową lokalizację.
- **Permission issues:** Upewnij się, że aplikacja ma uprawnienia do zapisu w docelowym folderze.
- **Large files:** W przypadku bardzo dużych osadzonych plików, rozważ zwiększenie rozmiaru sterty JVM lub przetwarzanie plików w mniejszych partiach.
