## 性能考虑
当处理大型 PDF（数百页或高分辨率图像）时，请牢记以下提示：

- **分块处理** – 分批创建和标记元素，而不是一次性加载整个文档。  
- **提前释放** – 完成后调用 `document.dispose()` 释放本机资源。  
- **内存管理** – 避免长时间保留大型对象；在循环中使用局部变量。
