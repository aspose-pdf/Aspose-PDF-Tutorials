## Průvodce implementací

### Extrahování souborů z PDF portfolia

#### Přehled

Tato sekce vás provede, jak **extrahovat vložené soubory PDF** z PDF portfolia. To je zvláště užitečné při práci s dokumenty obsahujícími více typů médií nebo datových souborů.

#### Implementace krok za krokem

**1. Načtěte zdrojové PDF portfolio**  

Načtěte své PDF portfolio do paměti. Třída `Document` je nejvyšší objekt Aspose.PDF, který představuje jeden PDF soubor v paměti.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. Získejte kolekci vložených souborů**  

Metoda `getEmbeddedFiles()` vrací kolekci, která obsahuje každý soubor vložený v portfoliu.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. Procházejte a extrahujte každý soubor**  

Procházejte každou položku v kolekci a zapisujte souborový stream na disk. Objekt `FileSpecification` poskytuje původní název souboru a obsahový stream.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

V tomto úryvku:
- `input` získává obsahový stream každého vloženého souboru.
- adresáře jsou vytvářeny za běhu pomocí `mkdirs()`.
- soubory jsou zapisovány na disk pomocí bufferovaného `FileOutputStream`.

#### Tipy pro řešení problémů

- **Soubor nenalezen:** Ověřte, že cesta k PDF (`Portfolio_output.pdf`) ukazuje na správné umístění.
- **Problémy s oprávněním:** Ujistěte se, že aplikace má práva zápisu do cílové složky.
- **Velké soubory:** Pro velmi velké vložené soubory zvažte zvýšení velikosti haldy JVM nebo zpracování souborů v menších dávkách.

Při práci s velkými portfolii mějte na paměti tyto tipy:

- **Správa paměti:** Přidělte dostatečnou haldu (`-Xmx`) pro zpracování velkých PDF.
- **Efektivita streamů:** Používejte bufferované streamy (jak je ukázáno) ke snížení I/O režie.
- **Dávkové zpracování:** Zpracovávejte soubory ve skupinách, aby nedošlo k vyčerpání systémových zdrojů.

## Časté problémy a řešení

| Problém | Příčina | Řešení |
|-------|-------|----------|
| **OutOfMemoryError** | PDF příliš velké pro výchozí haldu | Zvyšte JVM haldu (`-Xmx2g`) nebo zpracovávejte soubory jeden po druhém |
| **Prázdné výstupní soubory** | Vstupní stream není správně čten | Zajistěte, aby smyčka `input.read(buffer)` běžela až do `-1` |
