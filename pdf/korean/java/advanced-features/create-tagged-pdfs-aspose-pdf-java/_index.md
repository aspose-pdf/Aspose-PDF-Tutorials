## java pdf accessibility란?
**Java pdf accessibility**는 화면 읽기 프로그램, 점자 디스플레이 및 기타 보조 도구가 해석할 수 있는 PDF 파일을 만드는 관행입니다. 적절한 태깅은 논리적인 읽기 순서, 제목, 표 및 그림을 정의하여 사용자가 사용하는 장치와 관계없이 모든 사용자가 의도된 대로 콘텐츠를 경험하도록 보장합니다.

## pdf에 태그를 추가하는 이유는?

- **WCAG 2.1 및 PDF/UA 표준** 준수  
- **검색 가능성 및 탐색** 향상  
- **미래 대비** 접근성 도구를 위한 문서
