### PDF 포트폴리오에서 파일 추출

#### 개요
이 섹션에서는 PDF 포트폴리오에서 **extract embedded files pdf**를 수행하는 방법을 안내합니다. 여러 종류의 미디어 또는 데이터 파일이 포함된 문서를 다룰 때 특히 유용합니다.

#### 단계별 구현
**1. 소스 PDF 포트폴리오 로드**  
PDF 포트폴리오를 메모리로 로드합니다. `Document` 클래스는 메모리 내에서 단일 PDF 파일을 나타내는 Aspose.PDF의 최상위 객체입니다.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. 임베디드 파일 컬렉션 가져오기**  
`getEmbeddedFiles()` 메서드는 포트폴리오에 임베디드된 모든 파일을 보유하는 컬렉션을 반환합니다.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. 각 파일을 반복하며 추출**  
컬렉션의 각 항목을 순회하면서 파일 스트림을 디스크에 씁니다. `FileSpecification` 객체는 원본 파일 이름과 콘텐츠 스트림을 제공합니다.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

이 코드 스니펫에서:
- `input`은 각 임베디드 파일의 콘텐츠 스트림을 가져옵니다.
- `mkdirs()`를 사용하여 디렉터리를 즉시 생성합니다.
- 버퍼링된 `FileOutputStream`을 사용하여 파일을 디스크에 씁니다.

#### 문제 해결 팁
- **파일을 찾을 수 없음:** PDF 경로(`Portfolio_output.pdf`)가 올바른 위치를 가리키는지 확인하십시오.
- **권한 문제:** 애플리케이션이 대상 폴더에 대한 쓰기 권한을 가지고 있는지 확인하십시오.
- **대용량 파일:** 매우 큰 임베디드 파일의 경우 JVM 힙 크기를 늘리거나 파일을 더 작은 배치로 처리하는 것을 고려하십시오.

## 일반적인 문제 및 해결책
| 문제 | 원인 | 해결책 |
|-------|-------|----------|
| **OutOfMemoryError** | 기본 힙에 비해 PDF가 너무 큼 | JVM 힙(`-Xmx2g`)을 늘리거나 파일을 하나씩 처리하십시오 |
| **Empty output files** | 입력 스트림이 올바르게 읽히지 않음 | `input.read(buffer)` 루프가 `-1`이 될 때까지 실행되는지 확인하십시오 |
| **Missing files after extraction** | `fileSpecification.getName()`이 디렉터리 없이 상대 경로를 반환합니다 | 예시와 같이 `file.getParentFile().mkdirs()`를 사용하여 누락된 폴더를 생성하십시오 |
