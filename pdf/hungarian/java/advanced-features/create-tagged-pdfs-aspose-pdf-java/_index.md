## Az Aspose.PDF for Java beállítása
Mielőtt a kódba merülnénk, adjuk hozzá a könyvtárat a projektünkhöz.

Add hozzá a következő függőséget a `pom.xml` fájlodhoz:

```xml
<dependency>
```
