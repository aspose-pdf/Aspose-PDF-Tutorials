### Fájlok kinyerése PDF portfólióból

#### Áttekintés

Ez a rész bemutatja, hogyan **extract embedded files pdf** egy PDF portfólióból. Különösen hasznos, ha többféle média‑ vagy adatfájlt tartalmazó dokumentumokkal dolgozik.

#### Lépésről lépésre megvalósítás

**1. Forrás PDF portfólió betöltése**  

Töltse be a PDF portfóliót a memóriába. A `Document` osztály az Aspose.PDF legfelső szintű objektuma, amely egyetlen PDF fájlt képvisel a memóriában.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. Beágyazott fájlok gyűjteményének lekérése**  

A `getEmbeddedFiles()` metódus egy gyűjteményt ad vissza, amely a portfólióban beágyazott összes fájlt tartalmazza.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. Iterálás és minden fájl kinyerése**  

Iteráljon a gyűjtemény minden elemén, és írja a fájl adatfolyamát a lemezre. A `FileSpecification` objektum biztosítja az eredeti fájlnevet és a tartalom adatfolyamát.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

Ebben a kódrészletben:
- `input` a beágyazott fájl adatfolyamát olvassa.
- A könyvtárakat a `mkdirs()` metódussal hozza létre futás közben.
- A fájlokat egy pufferelt `FileOutputStream`‑mel írja a lemezre.

#### Hibaelhárítási tippek

- **File not found:** Ellenőrizze, hogy a PDF útvonal (`Portfolio_output.pdf`) a megfelelő helyre mutat.
- **Permission issues:** Győződjön meg arról, hogy az alkalmazásnak írási jogosultsága van a célmappához.
- **Large files:** Nagyon nagy beágyazott fájlok esetén fontolja meg a JVM heap méretének növelését, vagy dolgozza fel a fájlokat kisebb adagokban.
