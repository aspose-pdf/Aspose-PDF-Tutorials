# Como criar documentos PDF com Aspose.PDF para Java

Aspose.PDF for Java é uma biblioteca robusta que permite aos desenvolvedores gerar, editar e converter arquivos PDF programaticamente. Nesta visão geral, você descobrirá como **criar PDFs** do zero, a partir de modelos e de outros formatos de origem, enquanto personaliza o layout e a aparência.

## Como criar documentos PDF com Aspose.PDF para Java

Carregue o JAR do Aspose.PDF no seu projeto, instancie um objeto `Document`, adicione páginas, insira texto, imagens ou formas e, finalmente, chame `save`. **`Document` é a classe central que representa um documento PDF e fornece métodos para manipulação.** Esse padrão simples de duas etapas — inicializar + salvar — cobre 95 % dos cenários típicos de geração de PDF e funciona em qualquer ambiente Java 8+. Para documentos grandes ou complexos, você também pode transmitir páginas para manter o uso de memória baixo.

### Por que escolher Aspose.PDF para Java?

Aspose.PDF for Java suporta **mais de 50 formatos de entrada e saída** (incluindo DOCX, HTML, SVG e LaTeX) e pode gerar PDFs com várias centenas de páginas sem carregar o arquivo inteiro na memória, graças ao seu mecanismo de gravação incremental. A biblioteca processa um relatório de 300 páginas em menos de 4 segundos em uma CPU padrão de 2,5 GHz, oferecendo desempenho previsível para serviços de alta taxa de transferência.
