# Κρυπτογράφηση PDF ώστε να επιτρέπεται μόνο η συμπλήρωση φορμών χρησιμοποιώντας Aspose.Pdf
Σε αυτό το σεμινάριο θα μάθετε πώς να ανοίξετε ένα υπάρχον PDF με Aspose.Pdf for .NET, να εφαρμόσετε κρυπτογράφηση AES‑256, να ορίσετε κωδικούς πρόσβασης προβολής και ιδιοκτήτη, και να περιορίσετε τα δικαιώματα του εγγράφου ώστε οι παραλήπτες να μπορούν μόνο να συμπληρώνουν πεδία φόρμας. Αυτή η προσέγγιση είναι χρήσιμη όταν χρειάζεται να προστατεύσετε το περιεχόμενο ενώ εξακολουθείτε να επιτρέπετε στους χρήστες να συμπληρώνουν διαδραστικές φόρμες. Ο κώδικας περιγράφει κάθε βήμα και αποθηκεύει το ασφαλισμένο PDF έτοιμο για διανομή.

1. Download Aspose.Pdf for .NET:
   Get the latest version from the [Aspose Downloads page](https://releases.aspose.com/pdf/net/).

2. Install via NuGet:
   - Open your Visual Studio project.
   - Navigate to the NuGet Package Manager (Tools > NuGet Package Manager > Manage NuGet Packages for Solution).
   - Search for "Aspose.Pdf" and click Install.

3. Add Namespace References:
   Add the following namespace at the top of your code file:

## Frequently asked questions

**Q: Τι μπορεί να κάνει ένας χρήστης με το PDF μετά την κρυπτογράφηση με `Permissions.FillForm`;**  
A: Όταν ανοίγεται με τον κωδικό πρόσβασης προβολής (χρήστη), το έγγραφο μπορεί να προβληθεί και τα πεδία φόρμας να συμπληρωθούν, αλλά όλες οι άλλες ενέργειες όπως η επεξεργασία κειμένου, η προσθήκη σχολίων ή η εξαγωγή περιεχομένου είναι αποκλεισμένες.

**Q: Πώς μπορώ να επιτρέψω πρόσθετα δικαιώματα, όπως εκτύπωση, ενώ εξακολουθώ να περιορίζω τα υπόλοιπα;**  
A: Συνδυάστε τα δικαιώματα χρησιμοποιώντας τον τελεστή bitwise OR, π.χ., `Permissions allowed = Permissions.FillForm | Permissions.Printing;` και περάστε την συνδυασμένη τιμή στο `pdfDoc.Encrypt`.

**Q: Έχει σημασία η σειρά των κωδικών πρόσβασης στο `pdfDoc.Encrypt(viewerPass, adminPass, …)`;**  
A: Ναι. Το πρώτο όρισμα είναι ο κωδικός πρόσβασης χρήστη (προβολής) που παρέχει τα περιορισμένα δικαιώματα, και το δεύτερο όρισμα είναι ο κωδικός πρόσβασης ιδιοκτήτη (διαχειριστή) που παρέχει πλήρη έλεγχο του εγγράφου.

**Q: Τι συμβαίνει αν το PDF προέλευσης είναι ήδη προστατευμένο με κωδικό πρόσβασης;**  
A: Το Aspose.Pdf θα προκαλέσει εξαίρεση όταν προσπαθήσει να ανοίξει ένα ήδη κρυπτογραφημένο αρχείο· πρέπει πρώτα να το ανοίξετε με τον υπάρχοντα κωδικό πρόσβασης, να αφαιρέσετε ή να τροποποιήσετε την προστασία και, στη συνέχεια, να εφαρμόσετε τις νέες ρυθμίσεις κρυπτογράφησης.
