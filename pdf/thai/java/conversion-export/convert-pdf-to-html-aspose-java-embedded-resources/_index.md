# แปลง PDF เป็น HTML พร้อมฝังทรัพยากรทั้งหมดโดยใช้ Aspose.PDF for Java

## บทนำ

การแปลง PDF เป็น HTML ด้วย **pdf to html java** อาจซับซ้อนเมื่อคุณต้องการให้ฟอนต์ รูปภาพ และสไตล์ทั้งหมดคงเดิม Aspose.PDF for Java จัดการความซับซ้อนนี้โดยให้คุณสร้างไฟล์ HTML เดียวที่ฝังทรัพยากรทั้งหมดโดยตรงใน markup ในบทแนะนำนี้คุณจะได้เรียนรู้วิธีทำ **aspose pdf html conversion** อย่างเต็มรูปแบบ ฝังทรัพยากรใน HTML และเก็บ **pdf to html images** ไว้ในผลลัพธ์โดยตรง

### คำตอบอย่างรวดเร็ว
- **Aspose.PDF สามารถฝังฟอนต์และรูปภาพได้หรือไม่?** ใช่ – มันฝังฟอนต์และรูปภาพ raster ทั้งหมดโดยตรงลงใน HTML.  
- **ฉันจะได้ไฟล์ HTML เดียวหรือไม่?** การตั้งค่า `PartsEmbeddingModes.EmbedAllIntoHtml` จะสร้างผลลัพธ์เป็นไฟล์เดียว.  
- **ไลบรารีหลักที่ต้องใช้คืออะไร?** แพ็กเกจ `aspose-pdf` ของ Maven/Gradle.  
- **ต้องมีใบอนุญาตเพื่อใช้ฟีเจอร์นี้หรือไม่?** สามารถใช้รุ่นทดลองได้ แต่ใบอนุญาตถาวรจะลบข้อจำกัดการประเมิน.  
- **สามารถรันบน Java 11+ ได้หรือไม่?** แน่นอน – Aspose.PDF รองรับ JDK เวอร์ชันใหม่ๆ.

## pdf to html java คืออะไร?

`pdf to html java` คือกระบวนการแปลงเอกสาร PDF ให้เป็นรูปแบบ HTML อย่างโปรแกรมเมติกโดยใช้ไลบรารี Java เทคนิคนี้เหมาะสำหรับการเผยแพร่บนเว็บ การเก็บเอกสารระยะยาว หรือการรวม PDF เข้าในกระบวนการจัดการเนื้อหา ที่ต้องการรูปแบบเบาและเข้ากันได้กับเบราว์เซอร์

## ทำไมต้องฝังทรัพยากรใน HTML?

การฝังฟอนต์ รูปภาพ และ CSS ลงใน HTML ทำให้ไม่ต้องพึ่งพาไฟล์ภายนอก รับประกันว่าหน้าจะเรนเดอร์อย่างถูกต้องแม้ไม่มีการเชื่อมต่ออินเทอร์เน็ต ในอีเมลคลไอเอนท์ หรือบน static site generator ที่ไม่สามารถดึงทรัพยากรภายนอกได้ นอกจากนี้ยังทำให้การปรับใช้ง่ายขึ้น เพราะไฟล์เดียวสามารถคัดลอกหรือควบคุมเวอร์ชันได้โดยไม่ต้องกังวลเกี่ยวกับโฟลเดอร์ทรัพยากรที่หายไป และยังช่วยเพิ่มประสิทธิภาพการโหลดโดยลดจำนวนคำขอ HTTP

## คู่มือการดำเนินการ

ต่อไปเราจะเดินผ่านขั้นตอนการแปลงจริง

### การโหลดเอกสาร PDF
คลาส `Document` เป็นอ็อบเจ็กต์ระดับบนสุดของ Aspose.PDF ที่แทนไฟล์ PDF หนึ่งไฟล์ในหน่วยความจำ หลังจากสร้างอินสแตนซ์แล้ว คุณสามารถเข้าถึงหน้า, ทรัพยากร, และเมตาดาต้าได้

```java
import com.aspose.pdf.Document;

String dataDir = "YOUR_DOCUMENT_DIRECTORY";
Document doc = new Document(dataDir + "/input.pdf");
```

### การกำหนดค่าตัวเลือกการบันทึก HTML
`HtmlSaveOptions` กำหนดวิธีการเรนเดอร์ PDF เป็น HTML โดยตั้งค่า `PartsEmbeddingModes` เป็น `EmbedAllIntoHtml` ทุกฟอนต์ รูปภาพ และกฎ CSS จะถูกเขียนเป็น inline ทำให้ได้ไฟล์ที่เป็นอิสระ

```java
import com.aspose.pdf.HtmlSaveOptions;
import com.aspose.pdf.LettersPositioningMethods;

HtmlSaveOptions newOptions = new HtmlSaveOptions();
newOptions.setRasterImagesSavingMode(HtmlSaveOptions.RasterImagesSavingModes.AsEmbeddedPartsOfPngPageBackground);
newOptions.setFontSavingMode(HtmlSaveOptions.FontSavingModes.SaveInAllFormats);
newOptions.setPartsEmbeddingMode(HtmlSaveOptions.PartsEmbeddingModes.EmbedAllIntoHtml);
newOptions.setLettersPositioningMethod(LettersPositioningMethods.UseEmUnitsAndCompensationOfRoundingErrorsInCss);
newOptions.setSplitIntoPages(false); // Combine all pages into a single HTML file
```

### การปรับแต่งกลยุทธ์การบันทึก
คุณสามารถปรับการจัดการรูปภาพ raster, การย่อขนาด CSS, และการแทรก JavaScript ผ่านอ็อบเจ็กต์ options ได้ สำหรับกรณีส่วนใหญ่ การตั้งค่าเริ่มต้นให้สมดุลระหว่างขนาดไฟล์และความแม่นยำได้ดี

```java
import java.io.FileOutputStream;

newOptions.setCustomHtmlSavingStrategy(new HtmlSaveOptions.HtmlPageMarkupSavingStrategy() {
    public void invoke(HtmlSaveOptions.HtmlPageMarkupSavingInfo htmlSavingInfo) {
        try {
            byte[] resultHtmlAsBytes = new byte[(int) htmlSavingInfo.getContentStream().available()];
            htmlSavingInfo.getContentStream().read(resultHtmlAsBytes, 0, resultHtmlAsBytes.length);

            FileOutputStream fos = new FileOutputStream("YOUR_OUTPUT_DIRECTORY/allResourceEmbeddedInSingleResultantStream.html");
            fos.write(resultHtmlAsBytes);
            fos.close();
        } catch (Exception e) {
            e.printStackTrace(); // Handle exceptions such as IOException and FileNotFoundException
        }
    }
});
```

### การบันทึกเอกสาร
เมธอด `save` จะเขียน HTML ลงดิสก์ เนื่องจากทรัพยากรทั้งหมดถูกฝังไว้ คุณจะได้ไฟล์ `.html` ไฟล์เดียวที่สามารถเปิดได้ทุกที่โดยไม่ต้องมีไฟล์เพิ่มเติม

```java
String outHtmlFile = "YOUR_OUTPUT_DIRECTORY/ThisFileWillNotAppearOnDisk.html";
doc.save(outHtmlFile, newOptions);
```

- **การเก็บเอกสารระยะยาว** – รักษา PDF พร้อมทรัพยากรครบถ้วนสำหรับการจัดเก็บระยะยาว.

## ข้อควรพิจารณาด้านประสิทธิภาพ

- **การเพิ่มประสิทธิภาพทรัพยากร** – `setRasterImagesSavingMode` ฝังรูปภาพอย่างมีประสิทธิภาพโดยไม่ทำให้ไฟล์บวม.  
- **การจัดการหน่วยความจำ** – ตรวจสอบการใช้ heap ของ Java โดยเฉพาะกับ PDF ขนาดใหญ่ เพื่อหลีกเลี่ยง `OutOfMemoryError`.  
- **การประมวลผลแบบอะซิงโครนัส** – สำหรับการแปลงเป็นชุด ให้รันแต่ละการแปลงในเธรดของตนเองหรือใช้ executor service.
