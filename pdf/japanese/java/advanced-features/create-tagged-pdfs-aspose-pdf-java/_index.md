## パフォーマンス上の考慮点
数百ページや高解像度画像を含む大規模 PDF を扱う際は、以下の点に留意してください：

- **Chunk processing** – ドキュメント全体を一度にロードするのではなく、バッチで要素を作成・タグ付けする。  
- **Dispose early** – 完了したら `document.dispose()` を呼び出してネイティブリソースを解放する。  
- **Memory management** – 不要に大きなオブジェクトを保持しないようにし、ループ内ではローカル変数を使用する。
