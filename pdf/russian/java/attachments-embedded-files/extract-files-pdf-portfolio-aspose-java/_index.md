### Извлечение файлов из PDF‑портфеля

#### Обзор

Этот раздел объясняет, как **extract embedded files pdf** из PDF‑портфеля. Это особенно полезно при работе с документами, содержащими несколько типов медиа или файлов данных.

#### Пошаговая реализация

**1. Загрузка исходного PDF‑портфеля**  

Загрузите ваш PDF‑портфель в память. Класс `Document` — это объект верхнего уровня Aspose.PDF, представляющий один PDF‑файл в памяти.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. Получение коллекции вложенных файлов**  

Метод `getEmbeddedFiles()` возвращает коллекцию, содержащую каждый файл, вложенный в портфель.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. Итерация и извлечение каждого файла**  

Пройдите по каждому элементу коллекции и запишите поток файла на диск. Объект `FileSpecification` предоставляет оригинальное имя файла и поток содержимого.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

В этом фрагменте:
- `input` получает поток содержимого каждого вложенного файла.
- Каталоги создаются «на лету» с помощью `mkdirs()`.
- Файлы записываются на диск с использованием буферизованного `FileOutputStream`.

#### Советы по устранению неполадок

- **Файл не найден:** Убедитесь, что путь к PDF (`Portfolio_output.pdf`) указывает на правильное место.
- **Проблемы с правами:** Убедитесь, что приложение имеет права записи в целевую папку.
- **Большие файлы:** Для очень больших вложенных файлов рассмотрите возможность увеличения размера кучи JVM или обработки файлов небольшими партиями.

## Распространённые проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|----------|
| **OutOfMemoryError** | PDF слишком большой для кучи по умолчанию | Увеличьте размер кучи JVM (`-Xmx2g`) или обрабатывайте файлы по одному |
| **Empty output files** | Поток ввода читается некорректно | Убедитесь, что цикл `input.read(buffer)` выполняется до `-1` |
| **Missing files after extraction** | `fileSpecification.getName()` возвращает относительный путь без каталогов | Используйте `file.getParentFile().mkdirs()` как показано, чтобы создать недостающие папки |
