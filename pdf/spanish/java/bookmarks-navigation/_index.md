# Cómo agregar marcadores PDF en Java con Aspose.PDF

Agregar marcadores PDF programáticamente le permite convertir un documento estático en un recurso interactivo y fácil de navegar. En esta guía aprenderá **cómo agregar marcadores PDF** usando Aspose.PDF para Java, crear una Tabla de Contenidos (TOC), editar las preferencias del visor y guardar el archivo actualizado, todo sin edición manual ni herramientas de terceros.

## Respuestas rápidas
- **¿Qué significa “create PDF TOC Java”?**  
  Significa generar una Tabla de Contenidos jerárquica dentro de un PDF usando Java y Aspose.PDF, de modo que los lectores puedan saltar directamente a los capítulos.  
- **¿Por qué usar Aspose.PDF para la navegación?**  
  La API le brinda control programático total sobre los marcadores, hipervínculos y configuraciones del visor, eliminando la necesidad de Adobe Acrobat.  
- **¿Necesito una licencia?**  
  Una licencia temporal funciona para pruebas; se requiere una licencia completa para implementaciones en producción.  
- **¿Qué versiones de Java son compatibles?**  
  Java 8 y posteriores son totalmente compatibles con las últimas versiones de Aspose.PDF para Java.  
- **¿Puedo combinar marcadores con configuraciones del visor?**  
  Sí—usando la misma API puede editar la configuración del visor PDF mientras crea o actualiza marcadores.

## ¿Qué es “create PDF TOC Java”?

Una Tabla de Contenidos (TOC) es una lista jerárquica de entradas que enlazan a secciones dentro de un PDF.  
Crea una TOC PDF en Java construyendo programáticamente esta lista e insertándola como un conjunto de marcadores. Aspose.PDF le permite definir el título de cada entrada, la página de destino y el nivel de anidamiento, y luego escribe la estructura en el documento con solo unas pocas llamadas a la API.

## ¿Por qué usar Aspose.PDF para la navegación?

Aspose.PDF para Java es una biblioteca totalmente gestionada que le permite agregar, editar o eliminar marcadores e hipervínculos sin dependencias externas.  
Soporta **más de 50 formatos de entrada y salida** y puede procesar PDFs de hasta **5 GB** sin cargar todo el archivo en memoria, brindándole un control de navegación de alto rendimiento en Windows, Linux o macOS.

## Requisitos previos
- Java Development Kit (JDK) 8 o posterior.  
- Biblioteca Aspose.PDF para Java (descárguela del sitio oficial).  
- Un archivo de licencia temporal o completa para evitar limitaciones de evaluación.

## Editar la configuración del visor PDF para una mejor navegación
El objeto `ViewerPreferences` define cómo se abre un PDF en un lector.  
Puede establecer que el panel de marcadores sea visible por defecto, especificar el nivel de zoom inicial y elegir un diseño de página como vista de una sola página o vista continua. Estas configuraciones reducen el tiempo que los usuarios pasan buscando contenido, especialmente en informes con cientos de páginas.

## Abrir y guardar marcadores PDF programáticamente
La clase `Document` representa un archivo PDF en memoria.  
Abre un PDF con `new Document("input.pdf")`, modifica su árbol de marcadores mediante `document.getBookmarks()`, y luego llama a `document.save("output.pdf")`. Este flujo de trabajo le permite inyectar una TOC dinámica, reorganizar secciones o eliminar entradas obsoletas sin edición manual.

## Problemas comunes y soluciones
`LinkAction` especifica una acción de hipervínculo que navega a una página dentro del PDF.  
`optimizeResources()` reduce el uso de memoria al optimizar los recursos del PDF.

- **Los marcadores no aparecen después de guardar** – Asegúrese de llamar a `document.save()` después de modificar la colección de marcadores.  
- **Los hipervínculos apuntan a páginas incorrectas** – Verifique que los números de página de destino sean basados en cero al usar `LinkAction`.  
- **Configuraciones del visor ignoradas** – Algunos lectores de PDF sobrescriben las configuraciones incrustadas; pruebe con Adobe Acrobat Reader para confirmar.  
- **El procesamiento de PDF grandes falla** – Use `document.optimizeResources()` para reducir el uso de memoria en archivos de más de 2 GB.  

## Preguntas frecuentes

**P: ¿Puedo crear una TOC para PDFs encriptados?**  
R: Sí. Abra el documento encriptado proporcionando la contraseña, luego genere la TOC como de costumbre.

**P: ¿La “edición de configuraciones del visor PDF” afecta a todos los lectores de PDF?**  
R: La mayoría de los lectores modernos respetan las entradas PDF OpenAction y ViewerPreferences, aunque algunos lectores ligeros pueden ignorarlas.

**P: ¿Qué tan grande puede ser un PDF que pueda procesar con Aspose.PDF?**  
R: La biblioteca puede manejar PDFs de hasta **5 GB**; para archivos muy grandes, llame a `document.optimizeResources()` para mantener bajo el consumo de memoria.

**P: ¿Es posible combinar múltiples TOC de diferentes PDFs?**  
R: Absolutamente. Cargue cada documento, extraiga su árbol de marcadores y combínelos en una única estructura jerárquica antes de guardar.

**P: ¿Necesito una licencia separada para cada aplicación Java?**  
R: Una sola licencia cubre todas las aplicaciones en la misma máquina, pero revise los términos de licencia para los escenarios de implementación.
