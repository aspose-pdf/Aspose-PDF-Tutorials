## Menyiapkan Aspose.PDF untuk Java
Sebelum kita masuk ke kode, mari tambahkan pustaka ke proyek kita.

### Menggunakan Maven
Tambahkan dependensi berikut ke file `pom.xml` Anda:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-pdf</artifactId>
    <version>25.3</version>
</dependency>
```

### Menggunakan Gradle
Sertakan baris ini dalam file `build.gradle` Anda:

```gradle
implementation 'com.aspose:aspose-pdf:25.3'
```

### Inisialisasi dasar dan penyiapan
`Document` adalah kelas inti Aspose.PDF yang mewakili file PDF dalam memori. Setelah pustaka tersedia, buat dokumen PDF baru dan aktifkan penandaan:

```java
import com.aspose.pdf.Document;
// Initialize document object
Document document = new Document();
```

## Pertimbangan kinerja
Saat Anda menangani PDF besar (ratusan halaman atau gambar beresolusi tinggi), ingat tips berikut:

- **Pemrosesan chunk** – Buat dan beri tag elemen dalam batch daripada memuat seluruh dokumen sekaligus.  
- **Dispose awal** – Panggil `document.dispose()` saat selesai untuk membebaskan sumber daya native.  
- **Manajemen memori** – Hindari mempertahankan objek besar lebih lama dari yang diperlukan; gunakan variabel lokal di dalam loop.
