# Cara menambahkan bookmark PDF di Java dengan Aspose.PDF

Menambahkan bookmark PDF secara programatik memungkinkan Anda mengubah dokumen statis menjadi sumber daya interaktif yang mudah dinavigasi. Dalam panduan ini Anda akan belajar **cara menambahkan bookmark PDF** menggunakan Aspose.PDF untuk Java, membuat Daftar Isi (TOC), mengedit preferensi penampil, dan menyimpan file yang diperbarui—semua tanpa penyuntingan manual atau alat pihak ketiga.

## Jawaban cepat
- **Apa arti “create PDF TOC Java”?**  
  Artinya menghasilkan Daftar Isi hierarkis di dalam PDF menggunakan Java dan Aspose.PDF, sehingga pembaca dapat langsung melompat ke bab.  
- **Mengapa menggunakan Aspose.PDF untuk navigasi?**  
  API memberikan kontrol penuh secara programatik atas bookmark, hyperlink, dan pengaturan penampil, menghilangkan kebutuhan Adobe Acrobat.  
- **Apakah saya memerlukan lisensi?**  
  Lisensi sementara cukup untuk pengujian; lisensi penuh diperlukan untuk penyebaran produksi.  
- **Versi Java mana yang didukung?**  
  Java 8 dan yang lebih baru sepenuhnya kompatibel dengan rilis terbaru Aspose.PDF untuk Java.  
- **Bisakah saya menggabungkan bookmark dengan pengaturan penampil?**  
  Ya—dengan API yang sama Anda dapat mengedit pengaturan penampil PDF sambil membuat atau memperbarui bookmark.

## Apa itu “create PDF TOC Java”?

Daftar Isi (TOC) adalah daftar hierarkis entri yang menautkan ke bagian-bagian dalam PDF.  
Anda membuat PDF TOC di Java dengan membangun daftar ini secara programatik dan menyisipkannya sebagai sekumpulan bookmark. Aspose.PDF memungkinkan Anda menentukan judul setiap entri, halaman target, dan tingkat nesting, lalu menulis struktur tersebut ke dalam dokumen dengan beberapa panggilan API.

## Mengapa menggunakan Aspose.PDF untuk navigasi?

Aspose.PDF untuk Java adalah pustaka yang dikelola sepenuhnya yang memungkinkan Anda menambah, mengedit, atau menghapus bookmark dan hyperlink tanpa ketergantungan eksternal.  
Ia mendukung **lebih dari 50 format input dan output** serta dapat memproses PDF hingga **5 GB** tanpa memuat seluruh file ke memori, memberikan kontrol navigasi berperforma tinggi di Windows, Linux, atau macOS.

## Edit pengaturan penampil PDF untuk navigasi yang lebih baik
Objek `ViewerPreferences` menentukan cara PDF dibuka di pembaca.  
Anda dapat mengatur panel bookmark agar terlihat secara default, menentukan tingkat zoom awal, dan memilih tata letak halaman seperti tampilan satu‑halaman atau tampilan berkelanjutan. Pengaturan ini mengurangi waktu yang dihabiskan pengguna untuk mencari konten, terutama dalam laporan dengan ratusan halaman.

## Buka dan simpan bookmark PDF secara programatik
Kelas `Document` mewakili file PDF dalam memori.  
Anda membuka PDF dengan `new Document("input.pdf")`, memodifikasi pohon bookmark melalui `document.getBookmarks()`, lalu memanggil `document.save("output.pdf")`. Alur kerja ini memungkinkan Anda menyuntikkan TOC dinamis, menata ulang bagian, atau menghapus entri usang tanpa penyuntingan manual.

## Masalah umum dan solusi
`LinkAction` menentukan aksi hyperlink yang menavigasi ke halaman dalam PDF.  
`optimizeResources()` mengurangi penggunaan memori dengan mengoptimalkan sumber daya PDF.  

- **Bookmark tidak muncul setelah disimpan** – Pastikan Anda memanggil `document.save()` setelah memodifikasi koleksi bookmark.  
- **Hyperlink mengarah ke halaman yang salah** – Verifikasi nomor halaman tujuan berbasis nol saat menggunakan `LinkAction`.  
- **Pengaturan penampil diabaikan** – Beberapa pembaca PDF menimpa pengaturan yang disematkan; uji dengan Adobe Acrobat Reader untuk konfirmasi.  
- **Pemrosesan PDF besar gagal** – Gunakan `document.optimizeResources()` untuk mengurangi penggunaan memori pada file lebih besar dari 2 GB.
