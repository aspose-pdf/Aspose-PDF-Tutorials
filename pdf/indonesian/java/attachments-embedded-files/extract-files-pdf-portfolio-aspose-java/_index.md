### Mengekstrak file dari portofolio PDF

#### Ikhtisar

Bagian ini memandu Anda bagaimana **extract embedded files pdf** dari portofolio PDF. Ini sangat berguna ketika menangani dokumen yang berisi banyak jenis media atau file data.

#### Implementasi langkah demi langkah

**1. Load source PDF portfolio**  

Muat portofolio PDF Anda ke memori. Kelas `Document` adalah objek tingkat atas Aspose.PDF yang mewakili satu file PDF dalam memori.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. Retrieve embedded files collection**  

Metode `getEmbeddedFiles()` mengembalikan koleksi yang berisi setiap file yang tersemat dalam portofolio.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. Iterate and extract each file**  

Iterasikan setiap entri dalam koleksi dan tulis aliran file ke disk. Objek `FileSpecification` menyediakan nama file asli dan aliran konten.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

Dalam potongan kode ini:
- `input` mengambil aliran konten setiap file tersemat.
- Direktori dibuat secara otomatis dengan `mkdirs()`.
- File ditulis ke disk menggunakan `FileOutputStream` berbuffer.

#### Tips pemecahan masalah

- **File not found:** Verifikasi bahwa jalur PDF (`Portfolio_output.pdf`) mengarah ke lokasi yang benar.
- **Permission issues:** Pastikan aplikasi memiliki izin menulis untuk folder target.
- **Large files:** Untuk file tersemat yang sangat besar, pertimbangkan meningkatkan ukuran heap JVM atau memproses file dalam batch yang lebih kecil.

## Pertimbangan Kinerja

Saat bekerja dengan portofolio besar, perhatikan hal-hal berikut:

- **Memory management:** Alokasikan memori heap yang cukup (`-Xmx`) untuk menangani PDF besar.
- **Stream efficiency:** Gunakan aliran berbuffer (seperti yang ditunjukkan) untuk mengurangi beban I/O.
- **Batch processing:** Proses file dalam kelompok untuk menghindari kehabisan sumber daya sistem.

## Masalah Umum dan Solusinya

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **OutOfMemoryError** | PDF terlalu besar untuk heap default | Tingkatkan heap JVM (`-Xmx2g`) atau proses file satu per satu |
| **Empty output files** | Aliran masuk tidak dibaca dengan benar | Pastikan loop `input.read(buffer)` dijalankan hingga `-1` |
| **Missing files after extraction** | `fileSpecification.getName()` mengembalikan path relatif tanpa direktori | Gunakan `file.getParentFile().mkdirs()` seperti contoh untuk membuat folder yang hilang |
