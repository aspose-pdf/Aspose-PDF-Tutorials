## Wat is java pdf toegankelijkheid?
**Java pdf toegankelijkheid** is de praktijk van het creëren van PDF‑bestanden die kunnen worden geïnterpreteerd door schermlezers, Braille‑displays en andere assistieve hulpmiddelen. Juiste tagging definieert de logische leesvolgorde, koppen, tabellen en figuren, zodat elke gebruiker de inhoud zoals bedoeld ervaart, ongeacht het apparaat dat wordt gebruikt.

## Waarom tags aan pdf toevoegen?
Tagging zet een eenvoudige, ongestructureerde PDF om in een hiërarchisch document dat betekenis overbrengt aan assistieve technologieën. Door rollen zoals koppen, alinea's, tabellen en figuren te definiëren, stel je schermlezers in staat de inhoud logisch te presenteren, de navigatie te verbeteren en te voldoen aan toegankelijkheidsnormen.

- **Naleving** van WCAG 2.1 en PDF/UA‑standaarden  
- **Verbeterde doorzoekbaarheid** en navigatie voor alle gebruikers  
- **Toekomstbestendigheid** van je documenten voor opkomende toegankelijkheidstools

Voordat we in de code duiken, voegen we de bibliotheek toe aan ons project.

Voeg de volgende dependency toe aan je `pom.xml`‑bestand:


## Prestatie‑overwegingen
Wanneer je werkt met grote PDF's (honderden pagina's of hoge resolutie‑afbeeldingen), houd dan rekening met de volgende tips:

- **Chunk‑verwerking** – Maak en tag elementen in batches in plaats van het hele document in één keer te laden.  
- **Vroegtijdig opruimen** – Roep `document.dispose()` aan zodra je klaar bent om native resources vrij te geven.  
- **Geheugenbeheer** – Vermijd het langer vasthouden van grote objecten dan nodig; gebruik lokale variabelen binnen loops.
