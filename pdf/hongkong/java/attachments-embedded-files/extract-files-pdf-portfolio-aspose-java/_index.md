### 從 PDF 投資組合提取檔案

#### 概觀

本節說明如何 **extract embedded files pdf** 從 PDF 投資組合中提取。當處理包含多種媒體或資料檔案的文件時，特別有用。

#### 步驟實作

**1. 載入來源 PDF 投資組合**  

將您的 PDF 投資組合載入記憶體。`Document` 類別是 Aspose.PDF 的頂層物件，代表記憶體中的單一 PDF 檔案。

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. 取得嵌入檔案集合**  

`getEmbeddedFiles()` 方法會回傳一個集合，內含投資組合中所有嵌入的檔案。

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. 迭代並提取每個檔案**  

遍歷集合中的每個條目，將檔案串流寫入磁碟。`FileSpecification` 物件提供原始檔名與內容串流。

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

在此程式碼片段中：
- `input` 取得每個嵌入檔案的內容串流。
- 使用 `mkdirs()` 即時建立目錄。
- 使用緩衝的 `FileOutputStream` 將檔案寫入磁碟。

#### 疑難排解技巧

- **找不到檔案：** 確認 PDF 路徑 (`Portfolio_output.pdf`) 指向正確位置。
- **權限問題：** 確保應用程式對目標資料夾具有寫入權限。
- **大型檔案：** 對於非常大的嵌入檔案，請考慮增大 JVM 堆積大小或分批處理檔案。

## 效能考量

處理大型投資組合時，請留意以下建議：

- **記憶體管理：** 為處理大型 PDF 分配足夠的堆積記憶體 (`-Xmx`)。
- **串流效能：** 使用緩衝串流（如範例所示）以減少 I/O 開銷。
- **批次處理：** 將檔案分組處理，以免耗盡系統資源。

## 常見問題與解決方案

| 問題 | 原因 | 解決方案 |
|------|------|----------|
| **OutOfMemoryError** | PDF 太大，超出預設堆積大小 | 增加 JVM 堆積 (`-Xmx2g`) 或逐一處理檔案 |
| **Empty output files** | 輸入串流未正確讀取 | 確保 `input.read(buffer)` 迴圈執行至返回 `-1` 為止 |
| **Missing files after extraction** | `fileSpecification.getName()` 回傳沒有目錄的相對路徑 | 如範例所示使用 `file.getParentFile().mkdirs()` 以建立缺失的資料夾 |
