### Extraire des fichiers d'un portefeuille PDF

#### Vue d'ensemble

Cette section vous explique comment **extract embedded files pdf** depuis un portefeuille PDF. Cela est particulièrement utile lorsqu'il s'agit de documents contenant plusieurs types de médias ou fichiers de données.

#### Implémentation étape par étape

**1. Load source PDF portfolio**  
Chargez votre portefeuille PDF en mémoire. La classe `Document` est l'objet de niveau supérieur d'Aspose.PDF qui représente un fichier PDF unique en mémoire.

```java
import com.aspose.pdf.Document;

// Load source PDF portfolio
document = new Document("Portfolio_output.pdf");
```

**2. Retrieve embedded files collection**  
La méthode `getEmbeddedFiles()` renvoie une collection contenant chaque fichier intégré au portefeuille.

```java
import com.aspose.pdf.EmbeddedFileCollection;

// Get collection of embedded files
embeddedFiles = document.getEmbeddedFiles();
```

**3. Iterate and extract each file**  
Parcourez chaque entrée de la collection et écrivez le flux du fichier sur le disque. L'objet `FileSpecification` fournit le nom de fichier original et le flux de contenu.

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

// Iterate through individual files of the portfolio
for (int counter = 1; counter <= embeddedFiles.size(); counter++) {
    com.aspose.pdf.FileSpecification fileSpecification = embeddedFiles.get_Item(counter);
    try (InputStream input = fileSpecification.getContents()) {
        File file = new File(fileSpecification.getName());
        
        // Create path for file from PDF
        if (!file.getParentFile().exists()) {
            file.getParentFile().mkdirs();
        }
        
        // Extract and save the file
        try (FileOutputStream output = new FileOutputStream(file)) {
            byte[] buffer = new byte[4096];
            int n;
            while ((n = input.read(buffer)) != -1) {
                output.write(buffer, 0, n);
            }
        }
    } catch (IOException e) {
        System.err.println("An error occurred: " + e.getMessage());
    }
}
```

Dans cet extrait :
- `input` récupère le flux de contenu de chaque fichier intégré.  
- Les répertoires sont créés à la volée avec `mkdirs()`.  
- Les fichiers sont écrits sur le disque à l’aide d’un `FileOutputStream` tamponné.

#### Conseils de dépannage

- **Fichier non trouvé** : vérifiez que le chemin du PDF (`Portfolio_output.pdf`) pointe vers le bon emplacement.  
- **Problèmes d'autorisation** : assurez-vous que l'application possède les droits d'écriture sur le dossier cible.  
- **Fichiers volumineux** : pour des fichiers intégrés très volumineux, envisagez d'augmenter la taille du tas JVM ou de traiter les fichiers par lots plus petits.

## Considérations de performance

Lorsque vous travaillez avec de gros portefeuilles, gardez ces conseils à l'esprit :

- **Gestion de la mémoire** : allouez suffisamment de mémoire du tas (`-Xmx`) pour gérer les gros PDF.  
- **Efficacité des flux** : utilisez des flux tamponnés (comme indiqué) pour réduire la surcharge d'E/S.  
- **Traitement par lots** : traitez les fichiers par groupes pour éviter d'épuiser les ressources du système.

## Problèmes courants et solutions

| Problème | Cause | Solution |
|----------|-------|----------|
| **OutOfMemoryError** | PDF trop volumineux pour le tas par défaut | Augmenter le tas JVM (`-Xmx2g`) ou traiter les fichiers un par un |
| **Empty output files** | Le flux d'entrée n'est pas lu correctement | Assurez-vous que la boucle `input.read(buffer)` s'exécute jusqu'à `-1` |
| **Missing files after extraction** | `fileSpecification.getName()` renvoie un chemin relatif sans répertoires | Utilisez `file.getParentFile().mkdirs()` comme indiqué pour créer les dossiers manquants |
