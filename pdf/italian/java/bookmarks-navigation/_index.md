# Come aggiungere segnalibri PDF in Java con Aspose.PDF

Aggiungere segnalibri PDF programmaticamente ti consente di trasformare un documento statico in una risorsa interattiva e facile da navigare. In questa guida imparerai **come aggiungere segnalibri PDF** usando Aspose.PDF per Java, creare un indice (TOC), modificare le preferenze del visualizzatore e salvare il file aggiornato—tutto senza modifiche manuali o strumenti di terze parti.

## Risposte rapide
- **Cosa significa “create PDF TOC Java”?**  
  Significa generare un indice gerarchico all'interno di un PDF usando Java e Aspose.PDF, così i lettori possono saltare direttamente ai capitoli.  
- **Perché usare Aspose.PDF per la navigazione?**  
  L'API ti offre il pieno controllo programmatico su segnalibri, collegamenti ipertestuali e impostazioni del visualizzatore, eliminando la necessità di Adobe Acrobat.  
- **Ho bisogno di una licenza?**  
  Una licenza temporanea funziona per i test; è necessaria una licenza completa per le distribuzioni in produzione.  
- **Quali versioni di Java sono supportate?**  
  Java 8 e successive sono pienamente compatibili con le ultime versioni di Aspose.PDF per Java.  
- **Posso combinare i segnalibri con le impostazioni del visualizzatore?**  
  Sì—usando la stessa API puoi modificare le impostazioni del visualizzatore PDF mentre crei o aggiorni i segnalibri.

## Cos'è “create PDF TOC Java”?

Un indice (Table of Contents, TOC) è un elenco gerarchico di voci che collegano a sezioni all'interno di un PDF.  
Crei un TOC PDF in Java costruendo programmaticamente questo elenco e inserendolo come un set di segnalibri. Aspose.PDF ti consente di definire il titolo di ogni voce, la pagina di destinazione e il livello di nidificazione, quindi scrive la struttura nel documento con poche chiamate API.

## Perché usare Aspose.PDF per la navigazione?

Aspose.PDF per Java è una libreria completamente gestita che ti permette di aggiungere, modificare o eliminare segnalibri e collegamenti ipertestuali senza dipendenze esterne.  
Supporta **oltre 50 formati di input e output** e può elaborare PDF fino a **5 GB** senza caricare l'intero file in memoria, offrendoti un controllo di navigazione ad alte prestazioni su Windows, Linux o macOS.

## Prerequisiti
- Java Development Kit (JDK) 8 o più recente.  
- Libreria Aspose.PDF per Java (scaricabile dal sito ufficiale).  
- Un file di licenza temporaneo o completo per evitare le limitazioni della versione di valutazione.

## Modifica le impostazioni del visualizzatore PDF per una migliore navigazione
L'oggetto `ViewerPreferences` definisce come un PDF si apre in un lettore.  
Puoi impostare il pannello dei segnalibri come visibile per impostazione predefinita, specificare il livello di zoom iniziale e scegliere un layout di pagina come visualizzazione a pagina singola o continua. Queste impostazioni riducono il tempo che gli utenti spendono a cercare contenuti, soprattutto in report con centinaia di pagine.

## Apri e salva i segnalibri PDF programmaticamente
La classe `Document` rappresenta un file PDF in memoria.  
Apri un PDF con `new Document("input.pdf")`, modifica il suo albero di segnalibri tramite `document.getBookmarks()`, e poi chiama `document.save("output.pdf")`. Questo flusso di lavoro ti consente di inserire un TOC dinamico, riorganizzare sezioni o eliminare voci obsolete senza editing manuale.

## Problemi comuni e soluzioni
`LinkAction` specifica un'azione di collegamento ipertestuale che naviga a una pagina all'interno del PDF.  
`optimizeResources()` riduce l'uso di memoria ottimizzando le risorse PDF.  

- **I segnalibri non compaiono dopo il salvataggio** – Assicurati di chiamare `document.save()` dopo aver modificato la collezione dei segnalibri.  
- **I collegamenti ipertestuali puntano a pagine sbagliate** – Verifica che i numeri delle pagine di destinazione siano basati su zero quando usi `LinkAction`.  
- **Impostazioni del visualizzatore ignorate** – Alcuni lettori PDF sovrascrivono le impostazioni incorporate; testa con Adobe Acrobat Reader per confermare.  
- **Elaborazione di PDF di grandi dimensioni fallisce** – Usa `document.optimizeResources()` per ridurre l'uso di memoria per file più grandi di 2 GB.  

## Domande frequenti

**Q: Posso creare un TOC per PDF crittografati?**  
A: Sì. Apri il documento crittografato fornendo la password, quindi genera il TOC come al solito.

**Q: “Modifica le impostazioni del visualizzatore PDF” influisce su tutti i lettori PDF?**  
A: La maggior parte dei lettori moderni rispetta le voci PDF OpenAction e ViewerPreferences, sebbene alcuni lettori leggeri possano ignorarle.

**Q: Quanto grande può essere un PDF che posso elaborare con Aspose.PDF?**  
A: La libreria può gestire PDF fino a **5 GB**; per file molto grandi, chiama `document.optimizeResources()` per mantenere basso il consumo di memoria.

**Q: È possibile unire più TOC da PDF diversi?**  
A: Assolutamente. Carica ogni documento, estrai il suo albero di segnalibri e combinateli in una singola struttura gerarchica prima di salvare.

**Q: Ho bisogno di una licenza separata per ogni applicazione Java?**  
A: Una singola licenza copre tutte le applicazioni sulla stessa macchina, ma verifica i termini di licenza per gli scenari di distribuzione.
